# Black Padel maps

`black-padel.json` adapts the OpenFreeMap Positron style to the Black Padel palette.
Style source: https://tiles.openfreemap.org/styles/positron
Map tiles: OpenFreeMap / OpenMapTiles / OpenStreetMap contributors.
Attribution remains visible within each map.

The React components in `components/ui/map.tsx` come from mapcn (MIT):
https://www.mapcn.dev/r/map.json
https://github.com/AnmolSaini16/mapcn
